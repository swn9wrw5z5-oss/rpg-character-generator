# 第二階段：角色生成核心

日期：2026-11-15。範圍僅為核心、Excel 轉檔、命令列入口與測試。分支 `dev/v5-phase2-core`；第一階段保留於 `audit/v5-phase1`。父目錄 Godot、原始 Excel 及第一階段證據不變。

## 檔案用途

| 路徑 | 用途 |
|---|---|
| `tools/export-v5.mjs` | 唯讀 Excel 轉 JSON；來源 SHA-256 核對，驗證成功後才取代目的 JSON |
| `tools/read-xlsx.ps1` | .NET 讀取 OOXML，不啟動 Excel、不執行巨集或外部連結 |
| `tools/import-workbook.mjs` | 依欄名／ID 正規化，保留原始欄位、狀態、座標及公式 |
| `tools/formula-contract.json` | 已支援的 V5 角色計算公式契約；公式改變時阻止匯入，要求檢閱 |
| `data/v5.json` | 由 V5 產生的設定、來源雜湊及資料警告 |
| `config/test-parameters.json` | 本次授權建立的暫定測試參數，非 Excel 正式設定 |
| `src/core.mjs` | 無 DOM、無 Node 專用匯入的 ES module，可供未來手機網頁使用 |
| `src/validate.mjs`、`src/schema.mjs` | 資料、引用、尺寸、權重與區間驗證 |
| `tools/generate.mjs` | 單角色生成及完整開發者結果輸出 |
| `test/` | 核心、無效資料、Seed 與真實 Excel 轉檔測試 |

## 修改 Excel 後如何更新

1. 在 Excel 編輯並儲存 V5。轉檔工具只讀，不修改來源或另存工作簿。不讀舊版回補。
2. 在此目錄執行（找不到 `node` 時，使用 README 的 `$node` 絕對路徑）：

```powershell
node tools/export-v5.mjs 'C:\Users\johnn\Downloads\RPG_角色生成器_V5_完整可編輯.xlsx' data/v5.json
node --test
node tools/generate.mjs --seed v5-demo --output outputs/demo.json
```

輸出只接受 `.json`，原 Excel 無法被當成輸出覆寫。轉檔失敗時不取代上一份有效 JSON，結束碼為1。警告列於命令列與 JSON；重大錯誤阻止匯出。來源 Excel 不需放入程式目錄或 Git。

這不是通用 Excel 公式引擎。有效設定欄中的數字／旗標必須正確；公式目前只允許跨表直接引用，例如 `計分參數!$B$11`，會重新解析來源值，**不依賴快取**。循環、缺少引用、共享公式或未支援公式會明確拒絕，不以舊值補上。天賦「引用檢查」等非操作欄公式保留為證據，改由 JavaScript 按 ID 重新驗證。

`角色計算` 的現有公式逐格比對支援契約。只更改數值、權重、區間或原欄位資料不需改核心；新增資料依主鍵列掃描，不受舊公式範圍端點限制。若更動 Excel 計算公式本身、刪改欄名或新增機制，須先檢閱支援範圍，不靜默沿用舊程式算式。`V4原值與註解` 不進入設定；其他規格／試算頁作 referenceSheets 保留，非預設回補來源。

修改能力上下限後，測試格點步距必須整除區間，否則回報參數錯誤；可調整測試參數，不自行擴張或截短 Excel 範圍。

## 生成與重現

```powershell
# 隨機種族：按 V5 啟用種族的出現權重
node tools/generate.mjs --seed v5-demo --output outputs/random.json

# 指定啟用種族；不要求該種族隨機權重大於0
node tools/generate.mjs --seed v5-demo --species S003 --output outputs/wolf.json

# 直接重現某一索引，不受之前指定過哪些種族影響
node tools/generate.mjs --seed v5-demo --species S003 --index 12 --output outputs/wolf-12.json

# 可指定另一份測試參數檔
node tools/generate.mjs --seed trial --params config/test-parameters.json
```

結束碼：0=成功、1=設定／轉檔／命令列錯誤、2=本次生成失敗。失敗輸出 `ok:false`、錯誤與已知計算明細，`character:null`；候選不是有效角色。未知種族或池不足等早期錯誤可能尚無候選／分數，`calculation:null`。

完整結果包含角色ID、族系／種族ID、四項能力及評級、個性／技能／天賦ID、文字外觀、背包寬高、每項計分分錄、四類小計、總分、預算／剩餘額、培養值、判級依據及警告。技能與天賦明列效果未實作，施放成本未確認，不以0宣稱免費。

`replay` 保存 Seed、索引、指定種族請求、算法版本、Excel SHA-256、資料／參數指紋與完整測試參數。PRNG 為 FNV-1a（UTF-16字碼）初始化的 Mulberry32；不使用 Math.random、日期或隨機 UUID。每索引從 `[seed,index]` 獨立初始化；抽樣順序為種族→尺寸→每項能力與評級→個性→天賦→技能→計分→安全外觀選項。相同條件可重現，不同資料／設定不保證相同。

資料指紋與角色ID中的32位 hash只供除錯識別，非密碼學雜湊，也不作跨系統唯一識別保證；Excel來源另有 SHA-256。

## 集中的暫定測試參數

| 參數 | 預設／意義 |
|---|---|
| `budget` | 400；試算預算，不按稀有度設定 |
| 尺寸分布 | 種族範圍內寬高分別均勻整數；未猜測「尺寸偏好強度1.5」的公式 |
| `abilitySteps` | HP=1、MP=1、HP回復=0.5、MP回復=0.2；合法上下界間均勻格點，與「每分提升量」不同 |
| `growthWeights` | 四能力各有 D/C/B/A/S 五權重，目前皆1，分別獨立抽取 |
| `personalityCount` | 1（可0或1）；按 Excel 個性權重，備註不轉成能力效果 |
| `skillCount` | 1–5均勻個數，再從啟用且狀態確定的技能等權、不放回抽取 |
| `talentChance`／`talentCount` | 0／1–1；預設無天賦；可調出現率與個數範圍，天賦按 Excel 權重抽取 |
| `allowDraftTalents` | false；欲測兩個有效草案天賦須明確設true並提高出現率 |
| `talentSkillPolicy` | exclusive-acquisition：先抽天賦，普通技能池排除同技能ID；不從兩來源重複取得／計價。此為暫定政策 |
| `failurePolicy` | return-failure-no-retry：一次嘗試；不降低能力、減少技能、重抽種族或改預算 |
| `reservePolicy` | total-budget-only：依角色計算頁檢查總額；可改backpack-reserves，另套背包試算頁預留額檢查 |
| `appearancePolicy` | text-only-safe-options：只在單一相容規則與身體映射一致時抽色彩ID；不載入圖片 |

未知參數或未支援政策會拒絕，避免拼字錯誤被忽略。此為本次授權建立的實驗層，**不得覆蓋 Excel 能力值、成本、尺寸範圍、種族權重或稀有度區間**，不在程式另設舊版能力或備用數值。

零普通技能尚未開放：V5 `角色計算!B18` 要求第一技能欄有效，因此生成參數至少1。純算術 `scoreCharacter` 可以計算空技能清單，但不宣稱滿足該工作簿「可生成」條件。未來確認政策再改。

`backpack-reserves` 只檢查「預算−背包成本−天賦預留分 ≥ 最低保留能力分+最低保留成長分」，不強制實際能力與成長各達該下限。照第一階段保留差異，不補造正式分配規則。生成先提出完整候選，再核算預算；拒絕後不重試，分析時須保留失敗數，不能只看成功角色推論原始抽樣分布。

## 計分與未定資料

實作 V5 四類計分、成長效果示例及向下取整判級。範例331.25分→傳說，總值保留小數。取得成本加入詞綴價值並扣剩餘預算一次；天賦使用自身成本欄，對應技能不再加一遍。操作區完全不參與。

已知問題保留原資料：

- 四個 SKILL_* 引用缺失的天賦保留在 JSON／警告中，安全排除於生成池。
- 六項外觀問題保留，S006／S014／S015使用文字占位，不換素材、不補規則。
- 兩個可測草案天賦的 `targetId:null`，記錄角色歸屬及目標類型；FORM_001／SUMMON_001只保留原始欄，未冒用為真實綁定。
- 兩項回復能力的基準超界會警告；隨機值採合法上下限，不使用或改寫非法基準。
- 所有圖片、髮型動畫尚未載入；色彩選項ID不代表圖片或骨架效果完成。種族占位及成本草案狀態皆保留。

目前匯出14個警告=原10項＋2項基準超界＋2項綁定未定，0個阻擋錯誤。重複ID、非法權重／尺寸、空有效權重池、核心缺少引用、能力除數錯誤、稀有度衝突等會阻止啟動；不自動修正來源。

## JavaScript API

```javascript
import { createGenerator, scoreCharacter, playerView } from './src/core.mjs';

// 呼叫端先載入 data 與 testParameters JSON。
const generator = createGenerator(data, testParameters, 'seed-001');
const first = generator.next();
const specified = generator.next({ speciesId: 'S003' });
const replay = generator.generateAt(1, { speciesId: 'S003' });
// specified 與 replay 完全相同。
const player = playerView(first);
```

核心不做檔案IO、網路或畫面操作；需支援 ES modules、structuredClone 的現代瀏覽器。`playerView`保留使用者要求的四項成長評級，移除隱藏分、總分、整數判級分、預算、計算、Seed與設定；只是資料投影，不是靜態網站權限隔離。

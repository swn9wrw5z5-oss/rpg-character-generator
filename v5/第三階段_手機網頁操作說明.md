## 手機預覽與實機開啟

加上 `--qa` 啟動，可開啟 **http://127.0.0.1:4173/__qa/preview.html**。

這是以390×844 CSS px iframe載入**實際同一份網頁**的可操作預覽，對應iPhone 12 Pro直式參考尺寸；可捲動查看技能、天賦、背包與開發者明細。不是截圖、角色假資料或另一份生成器。若要用瀏覽器裝置工具檢查，直接開主頁，分別設定320、375、390、430px寬度。

同Wi-Fi的iPhone可以使用：

```powershell
node tools/serve.mjs --host 0.0.0.0
```

在iPhone Safari輸入 `http://電腦的區域網路IP:4173/`。手機的127.0.0.1指手機自身，不能用來連電腦。若系統阻擋區域連線，先檢查既有網路／防火牆設定；本專案不修改這些設定。預設啟動僅監聽電腦本機。

## 操作

1. 選「全部隨機」，依V5啟用種族權重抽取；或從清單指定種族。占位種族會標「暫定」。變更選項後需再按生成才套用。
2. 輸入Seed，按「隨機生成角色」。每次呼叫第二階段 `createGenerator(...).generateAt(0, ...)`；相同Seed、種族與測試設定、資料會重現同一角色。
3. 想換一位角色，按角色卡下方「換 Seed，再生成」。這個按鈕只用瀏覽器crypto產生新Seed；能力、成長、種族、背包、天賦與稀有度仍全部交給既有核心。
4. 玩家模式顯示角色ID、族系、種族、稀有度、四能力／成長評級、個性、技能、先天天賦，以及實際寬高的背包格子。
5. 開發者模式可展開四類小計、逐項成本、隱藏潛力、總分、剩餘預算、向下取整判級、培養值、警告、完整測試參數與JSON。切換模式不重新生成角色。

Seed可以使用繁體中文。也可透過URL指定，例如 `http://127.0.0.1:4173/?seed=v5-demo&species=S003`。未指定則預設Seed v5-demo、全部隨機；頁面載入時會用核心產生一名初始角色。

## 顯示與錯誤處理

- UI沒有角色能力、成本或稀有度的另一套公式。所有欄位與計算明細來自核心；格式化小數僅供顯示，完整JSON保留原數值。
- 玩家模式使用核心 `playerView`，開發者DOM在玩家模式中是空的，不只是CSS藏起來。靜態網頁的原始JSON仍可查看；此模式不提供真正機密隔離。
- 保留V5原4項天賦缺少引用與6項外觀問題；不修正原始值。開發者可查看14個既有資料警告及本次生成提示。
- 技能效果尚未實作，天賦抽取預設關閉。若在既有集中測試參數中明確開啟草案天賦，角色卡會顯示「草案／綁定待確認」，不建立虛構形態或召喚物。
- 背包直接依核心結果建立 `width×height` 個格子，支援10×8的80格，沒有固定尺寸假資料。
- 預算不足顯示失敗，不暗中重抽。失敗候選不當作成功角色；開發者仍可查看核心失敗明細。空白Seed會提示並保留上一個有效角色。JSON／設定無法載入則明確報錯，沒有後備假角色。
- 顏色、圖片、動畫沒有新增生成規則；角色頭像用種族文字代替。頁面無外部字型、圖片或第三方分析服務。
